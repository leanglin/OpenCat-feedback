# 公开分析目录

此目录保存与公开反馈对应、经过脱敏的分析输出，不保存内部研究过程或私密对话。

使用 [TEMPLATE.md](TEMPLATE.md) 开始一份分析。建议文件名为 `YYYY-MM-DD-issue-N-short-topic.md`，并在正文链接原 Issue。没有可靠事实时明确标记“待确认”，不要编造成本、用户数量或测试结果。

每份分析应覆盖：
- 需求场景、证据和去重结果
- 用户价值、成本、风险和置信度
- 通用能力与定制需求的边界
- 最小可行方案、测试、验收、回滚
- 建议及待负责人决定的事项

“建议实施”仅为建议。代码修改、构建与发布需要负责人在私密对话中另行明确批准。
